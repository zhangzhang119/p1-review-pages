1核心知识点
print()[prɪnt]打印
  • 把括号里的内容输出到控制台（屏幕上）
  • 括号里可以是带引号的文字或符号，比如 "hello"
  • 它是 Python 的内置函数，不用导入就能直接用
  • 想多打印几行，就再写一行 print()
print("hello")          # 在屏幕上打印 hello
import[ɪmpɔːt]导入
  • 用来导入库，把别人写好的功能拿过来用
  • 写法：import 库名，比如 import pyttsx3
  • 导入后才能用库里的函数，例如 pyttsx3.speak()
  • 库名和函数名之间用英文点 . 连接
import pyttsx3          # 导入语音库
speak()[spiːk]说
  • pyttsx3 库里的函数，作用是把文字转成语音播放
  • 括号里一般写带引号的文字，比如 "hello"
  • 调用前要先 import pyttsx3
  • 调用时写成 pyttsx3.speak("你好")
import pyttsx3
pyttsx3.speak("hello")   # 让电脑念出 hello
# 注释[kəˈment]注释
  • # 号表示单行注释，写在代码前面
  • 三个连续的单引号 ''' 或双引号 """ 表示多行注释
  • 注释是对程序的说明解释，不会被运行
  • 写注释能帮自己和别人更好理解代码
# 这是一行注释，电脑会跳过它
print("hello")        # 也可以写在代码后面
💡 引号规则：print("hello") 里的文字是字符串，必须用英文引号包起来；不加引号，Python 会把它当成变量去找，找不到就报错。
💡 先导入再用：想用 speak() 这样的库函数，一定要先写 import pyttsx3，否则程序不认识这个函数，运行时会报错。
💡 注释不执行：# 后面、以及 '''...''' 里面的内容只是给人和老师看的说明，运行程序时会被自动跳过，随便写不会影响结果。

3程序参考 · 机械伙伴

🤖 哄小主人开心的机械伙伴机械伙伴 · print + speak

机械伙伴看到小主人伤心，显示一个表情符号，再说几句俏皮话哄他开心。

1第一步：导入 pyttsx3 语音库
2第二步：用 print 打印大号表情符号
3第三步：用 speak 让机械伙伴说话
import pyttsx3                       # 导入语音库
print(" ^ ^ ")                       # 表情：眼睛
print(" / \ / \ ")                   # 表情：嘴巴
print(" # # ")                       # 表情：身体
print(" ———— ")                      # 表情：底座
pyttsx3.speak("求抱抱")               # 让机械伙伴说话
pyttsx3.speak("不开心的事说出来就变开心啦")
