画圆与颜色填充知识点复习

circle 画圆 · 颜色填充 · begin_fill · end_fill

01学习 turtle 库中的 circle() 函数
02学习 turtle 库的颜色填充方法
03掌握 begin_fill 与 end_fill 搭配画实心图形
1核心知识点
circle()[ˈsɜːkl]圆圈
  • turtle 库的基本动作函数，用来画圆圈、圆弧
  • 第一个参数是半径，第二个是角度，第三个是步数
  • 后两个参数可以省略：circle(100) 画整圆
  • 角度 180 画半圆，步数 4 画菱形：circle(50,360,4)
import turtle as t
t.circle(100)            # 半径 100 的整圆
t.circle(50, 180)         # 半径 50 的半圆
begin_fill()[bɪˈɡɪn]开始填充
  • 放在画图之前，表示“开始记录填充区域”
  • 必须和 end_fill() 配对使用
  • 中间的图形会被填上颜色
  • 常与 fillcolor() 一起出现
import turtle as t
t.fillcolor("yellow")
t.begin_fill()             # 开始填充
t.circle(100)
t.end_fill()               # 结束填充
end_fill()[end]结束填充
  • 放在画图之后，表示“填充到此结束”
  • 和 begin_fill() 是一对
  • 漏写它图形填不上颜色
  • 一般紧跟在画图函数后面
t.begin_fill()
t.circle(100)
t.end_fill()               # 结束填充，内部变黄
fillcolor()[fɪl]填充颜色
  • 设置图形内部填充的颜色
  • 括号里写带引号的英文颜色名，如 "yellow"
  • 要搭配 begin_fill() 和 end_fill() 才生效
  • 只影响“里面”，画笔边色由 pencolor() 决定
t.fillcolor("yellow")       # 内部填充黄色
t.begin_fill()
t.circle(100)
t.end_fill()
seth()[set]设置方向
  • seth() 是 setheading 的简写，设置海龟朝向
  • 括号里写角度：0 朝右，90 朝上，270 朝下
  • 画圆弧前常用它定好起点方向
  • 本课本用于窗户与彩虹的起点朝向
t.seth(90)                # 方向朝上
t.circle(-600, 180)        # 画半圆弧
💡 实心图形三步走：fillcolor("颜色") → begin_fill() → 画图 → end_fill()。中间画的封闭图形才会被填上色。
💡 circle() 的参数：第一个是半径，正负决定顺/逆时针；第二是角度（可省，默认 360）；第三是步数（可省）。
💡 填充要配对：begin_fill() 和 end_fill() 缺一不可，漏掉任何一个图形都填不上颜色。

3程序参考 · 阳光小木屋

☀️ 绘制太阳太阳 · circle + 填充

1第一步：画笔粗细 10，橙色边
2第二步：黄色填充
3第三步：begin_fill 后画圆 circle(100)
4第四步：end_fill 填充，done 收工
import turtle as t
t.pensize(10)               # 画笔粗细 10
t.pencolor("orange")         # 橙色边
t.fillcolor("yellow")         # 黄色填充
t.begin_fill()              # 开始填充
t.circle(100)               # 画一个圆
t.end_fill()                # 结束填充
t.done()

🪟 绘制菱形窗户窗户 · goto + circle(4步) + 填充

1第一步：抬笔移动到 (0,-200)，方向 0
2第二步：黄色填充，begin_fill
3第三步：circle(50,360,4) 画菱形
4第四步：end_fill 填充
# 窗户代码：
t.penup()
t.goto(0, -200)            # 窗户起点
t.pendown()
t.seth(0)                  # 方向朝右
t.fillcolor("yellow")         # 黄色填充
t.begin_fill()              # 开始填充
t.circle(50, 360, 4)        # 半径50、整圈、4步=菱形
t.end_fill()                # 结束填充

🌈 绘制彩虹外层红弧彩虹 · goto + seth + circle(弧)

1第一步：红色画笔，抬笔到 (-600,-300)
2第二步：落笔，方向 90
3第三步：circle(-600,180) 画半圆弧
t.pencolor("red")            # 红色画笔
t.penup()
t.goto(-600, -300)         # 起点
t.pendown()
t.seth(90)                 # 方向朝上
t.circle(-600, 180)         # 半径600、180°半圆弧
