1核心知识点
select()[sɪˈlekt]选择
  • 是 mxcgame 库里的函数，用来选择一张或两张卡牌
  • 选择后会返回对应的卡牌，可以存进变量里
  • 语法：变量名 = m.select()
  • 需要先 import mxcgame as m 才能用
import mxcgame as m        # 导入游戏库
scard = m.select()             # 选择一张卡牌
attack()[əˈtæk]攻击
  • 是 mxcgame 库里的函数，对选择的对象发起攻击
  • 攻击的伤害由对应卡牌决定
  • 语法：m.attack(传入卡牌, 攻击对象)
  • 例：m.attack(scard, cmp) 攻击敌方 cmp
m.attack(scard, cmp)        # 用 scard 攻击 cmp
heal()[hiːl]治愈
  • 是 mxcgame 库里的函数，为对象恢复能量或血量
  • 恢复的数值由对应卡牌决定
  • 语法：m.heal(传入卡牌, 恢复对象)
  • 例：m.heal(scard, player) 为玩家回血
m.heal(scard, player)       # 用 scard 为 player 回血
combine()[kəmˈbaɪn]组合
  • 是 mxcgame 库里的函数，把卡牌组合成组合技
  • 如果不是对应组合关系，会提示组合错误
  • 语法：m.combine(传入卡牌)
  • 一般用于出两张牌的情况
m.combine(scard)             # 发动组合技
input()[ˈɪnpʊt]输入
  • 是 mxcgame 库里的函数，用来获取卡牌数量
  • 括号里写带引号的提示文字，如 "number"
  • 会返回玩家输入的内容（文字形式）
  • 常与 select() 搭配使用
num = m.input("number")       # 获取卡牌数量
💡 库函数调用规则：所有 mxcgame 函数都要先 import mxcgame as m，之后用 m.函数名() 的方式调用，例如 m.select()、m.attack()。
💡 引号规则：m.input("number")、m.print("error") 里的文字是字符串，要用英文引号包起来；而 energy、scard 这类变量和数字不能加引号。
💡 多分支判断：用 if / elif / else 处理出 1 张、2 张、其它数量卡牌的情况，谁写在前面先判断谁；能量不足时才提示 "lack energy"。

🎴 选择卡牌并出一张牌select · input · attack · heal

先选择卡牌、获取数量；数量为 "1" 时，根据卡牌类型发动攻击或治愈。

1第一步：用 select() 选择一张卡牌
2第二步：用 input() 获取卡牌数量
3第三步：数量等于 "1" 时判断能量
4第四步：攻击类卡牌 attack，其它卡牌 heal
while True:
    scard = m.select()            # 选择一张卡牌
    num = m.input("number")        # 获取卡牌数量
    if num == "1":                  # 出一张牌的情况
        if energy < 1:              # 能量不足
            m.print("lack energy")  # 提示能量不足
        else:
            energy = energy - 1       # 消耗 1 点能量
        if scard == "lb" or scard == "gy" or scard == "zf":
            m.attack(scard, cmp)    # 攻击类卡牌→攻击
        else:
            m.heal(scard, player)   # 其它卡牌→治愈

🃏 出两张牌组合技combine · 组合技

数量等于 "2" 时，使用 combine() 发动组合技，并消耗 2 点能量。

1第一步：判断数量是否等于 "2"
2第二步：能量小于 2 则提示不足
3第三步：否则发动组合技
4第四步：能量减少 2
# 任务一代码已完成
elif num == "2":                # 出两张牌的情况
    if energy < 2:              # 能量不足
        m.print("lack energy")  # 提示能量不足
    else:
        m.combine(scard)         # 发动组合技
        energy = energy - 2       # 消耗 2 点能量

❓ 其它数量提示错误print · 错误处理

数量既不是 "1" 也不是 "2" 时，用 print() 提示组合错误。

1第一步：前面两种情况都不成立
2第二步：提示组合错误 "error"
# 任务一、二代码已完成
else:
    m.print("error")           # 提示组合错误
