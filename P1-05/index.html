03掌握画笔移动到指定坐标的方法
1核心知识点
goto()[ˈɡəʊ tuː]去（某处）
  • 用 goto() 把画笔移动到指定的坐标位置
  • 括号里写 (x, y) 两个数字，分别是横、纵坐标
  • 移动时会留下画线（除非先抬笔）
  • 是 turtle 库里最常用的动作函数之一
import turtle
turtle.goto(300, 200)      # 移动到坐标 (300,200)
turtle.done()
penup()[penʌp]抬笔
  • 让画笔抬起来，移动时不再画线
  • 想“跳”到别处再画，先调用 penup()
  • 常与 goto() 搭配：抬笔 → 移动 → 落笔
  • 不抬笔直接 goto 会留下一条连线
import turtle
turtle.penup()                # 抬笔
turtle.goto(300, 200)      # 移动不画线
turtle.done()
pendown()[pendaʊn]落笔
  • 让画笔落下去，之后移动就会画线
  • 一般在 penup() + goto() 之后调用
  • 和 penup() 是一对相反的动作
  • 漏掉 pendown() 图形会“画不出来”
import turtle
turtle.penup()
turtle.goto(300, 200)
turtle.pendown()             # 落笔，准备画
turtle.done()
dot()[dɒt]点
  • 在当前位置画一个实心圆点
  • 括号里可写 dot(直径, "颜色")
  • 比如 dot(60,"yellow") 画一个黄色大点
  • 常用来画眼睛、按钮等小圆点
import turtle as t
t.penup()
t.goto(-40, 10)
t.pendown()
t.dot(60, "yellow")      # 画一个黄色圆点
t.done()
seth()[set]设置方向
  • seth() 是 setheading 的简写，设置海龟朝向
  • 括号里写角度：0 朝右，90 朝上，270 朝下
  • 改变方向后再 forward() 会朝新方向走
  • 不影响位置，只改变头朝向
import turtle as t
t.seth(270)               # 方向朝下
t.forward(60)             # 向下画 60
t.done()
💡 坐标小常识：屏幕正中心是 (0,0)，向右 x 变大，向上 y 变大，向左、向下则为负数。
💡 抬笔与落笔：penup() 之后移动不画线，想画之前一定要 pendown() 落笔，否则图形“消失”。
💡 顺序结构：程序从上往下一行一行执行。先 penup() → goto() 跳位置 → 再 pendown() 落笔画，顺序不能乱。

3程序参考 · 超级英雄武器铺

🔫 绘制连线子弹连线子弹 · goto + 颜色

1第一步：设置画笔颜色为 yellow
2第二步：依次 goto 到各坐标点连线
3第三步：回到起点闭合图形
4第四步：done() 收工
import turtle as t
t.pencolor("yellow")        # 画笔黄色
t.goto(0, 50)             # 连到 (0,50)
t.goto(150, 50)           # 连到 (150,50)
t.goto(250, 0)            # 连到 (250,0)
t.goto(150, -50)          # 连到 (150,-50)
t.goto(0, -50)            # 连到 (0,-50)
t.goto(0, 0)              # 回到起点
t.done()

👀 绘制超人眼睛超人眼睛 · penup + dot

1第一步：抬笔，移动到左眼位置 (-40,10)
2第二步：落笔，画一个黄色圆点 dot(60,"yellow")
3第三步：同样方法画右眼 (40,10)
# 左眼
t.penup()
t.goto(-40, 10)
t.pendown()
t.dot(60, "yellow")        # 左眼：黄色圆点
# 右眼
t.penup()
t.goto(40, 10)
t.pendown()
t.dot(60, "yellow")        # 右眼：黄色圆点

👑 绘制头饰头饰 · penup + seth + forward

1第一步：红色画笔，粗细 20
2第二步：抬笔移动到 (0,110)
3第三步：落笔，方向朝下 (seth 270)，前进 60
t.pencolor("red")           # 红色画笔
t.pensize(20)               # 粗细 20
t.penup()
t.goto(0, 110)            # 跳到头饰起点
t.pendown()
t.seth(270)                # 方向朝下
t.forward(60)              # 向下画 60
