1核心知识点
key()[kiː]按键
  • 是 mxcgame 库里的函数，按下键盘时自动调用
  • 会返回按下的按键：left 左键、right 右键
  • 常配合 if 判断移动方向
  • 例：m.key() == "left"
if m.key() == "left":        # 按下左键
    ball.x = ball.x - 10      # 雪球左移
draw()[drɔː]画
  • 是 mxcgame 库里的函数，设置角色造型
  • 括号里写造型编号
  • 常用来更换障碍物的样子
  • 语法：角色名.draw(造型编号)
obs.draw(3)                 # 把障碍物换成 3 号造型
collide()[kəˈlaɪd]碰撞
  • 是 mxcgame 库里的函数，判断两个角色是否碰撞
  • 碰到则返回 True，否则返回 False
  • 常配合 if 或 break 使用
  • 语法：m.collide(角色1, 角色2)
if m.collide(obs, ball):     # 障碍物碰到雪球
    break                      # 游戏结束
randint()[ˈrændɪnt]随机整数
  • 是 random 库里的函数，产生随机整数
  • 括号里写范围 a, b，包含两端
  • 用来给角色随机造型或随机位置
  • 需先 import random
import random
obs.x = random.randint(-100, 100)  # 随机左右位置
x / y 坐标[ˈkɔːdɪnət]位置属性
  • 创建角色后，自动有 x、y 属性控制位置
  • x 控制左右方向，y 控制上下方向
  • x 加 10 向右移动，y 减 6 向下移动
  • 例：ball.x = ball.x + 10 向右移动
ball.x = ball.x + 10          # 雪球向右移动
obs.y = obs.y - 6             # 障碍物向下移动
💡 坐标规则：角色位置由 x（左右）和 y（上下）决定；x 增大向右、y 减小向下。修改属性就能让角色移动。
💡 窗口边界：obs.y < -180 表示障碍物到达窗口底部，要重置到顶部 obs.y = 180 并随机换造型，否则会一直跑到画面外。
💡 碰撞检测：m.collide(角色1, 角色2) 碰到返回 True，常写成 if m.collide(obs, ball): break 来结束游戏或扣血。

⛷️ 雪球功能设置key · x坐标

用左右键控制雪球在窗口中左右移动。

1第一步：用 key() 获取按下的按键
2第二步：左键让 x 减 10
3第三步：右键让 x 加 10
while True:
    if m.key() == "left":        # 按下左键
        ball.x = ball.x - 10      # 雪球左移
    if m.key() == "right":       # 按下右键
        ball.x = ball.x + 10      # 雪球右移

🪨 障碍物功能设置draw · collide · randint

障碍物不断下落，到达底部换随机造型并回到顶部；碰到雪球则游戏结束。

1第一步：减少 y 坐标实现下落
2第二步：到底部换随机造型并回顶部
3第三步：碰撞雪球则游戏结束
while True:
    obs.y = obs.y - 6              # 障碍物向下移动
    if obs.y < -180:                # 到达窗口底部
        obs.draw(random.randint(1, 9))  # 换成随机造型
        obs.x = random.randint(-100, 100) # 随机左右位置
        obs.y = 180                   # 回到窗口顶部
    if m.collide(obs, ball):        # 碰到雪球
        break                          # 游戏结束

🪙 金币功能设置collide · randint · score

金币不断下落，碰到雪球分数加 1，到底部或碰雪球则回到顶部随机位置。

1第一步：减少金币 y 坐标实现下落
2第二步：碰雪球分数 score 加 1
3第三步：到底部或碰雪球回顶部随机位置
score = 0                        # 得分
while True:
    coin.y = coin.y - 6            # 金币向下移动
    if m.collide(coin, ball):      # 碰到雪球
        score = score + 1            # 分数加 1
    if coin.y < -180 or m.collide(coin, ball):  # 到底或碰雪球
        coin.y = 180                 # 回到窗口顶部
        coin.x = random.randint(-100, 100) # 随机左右位置
