1核心知识点
%[mɒd]取余 / 求模
  • % 求两个数相除后剩下的余数
  • 判断奇偶用 a % 2 == 0：余 0 是偶数
  • 余数不是 0，就是奇数
  • 闰年判断也常用 y % 400、y % 4、y % 100
if a % 2 == 0:
    print("偶数")      # 能被 2 整除
==[ɪˈkwəl]等于
  • 比较是否相等，相等返回 True
  • 常用于条件，如 a % 2 == 0
  • 和赋值 = 不同：== 是比较，= 是存放
  • 判断“不等”用 !=
y = 2000
if y % 400 == 0:        # 能被 400 整除
    print("闰年")
and[ænd]与 / 并且
  • and 表示“并且”，两边都为 True 才 True
  • 闰年里用 y % 4 == 0 and y % 100 != 0
  • 一边为 False，整体就为 False
  • 优先级比 or 高：先算 and 再算 or
elif y % 4 == 0 and y % 100 != 0:
    print("闰年")      # 被4整除且不被100整除
or[ɔːr]或 / 或者
  • or 表示“或者”，一边为 True 就 True
  • 闰年规则可写成 y%400==0 or (y%4==0 and y%100!=0)
  • 两边都 False，整体才 False
  • 优先级最低：用括号让逻辑更清楚
if y % 400 == 0 or (y % 4 == 0 and y % 100 != 0):
    print("闰年")
not[nɒt]非 / 取反
  • not 把 True 变 False、False 变 True
  • 逻辑优先级里 not 最高，其次 and，最后 or
  • 常和比较配合，如 not (y % 100 == 0)
  • 混合时用括号更清楚安全
if not (y % 100 == 0):
    print("不被100整除")
!=[nɒt ɪˈkwəl]不等于
  • 比较是否不相等，不等返回 True
  • 闰年里用 y % 100 != 0 排除整百年
  • 和 == 正好相反
  • 也是比较运算符，优先级高于逻辑
if y % 100 != 0:         # 不是整百年
    print("普通年")
💡 运算符优先级：算术运算符（如 %、*、+）> 比较运算符（如 ==、!=、>=）> 逻辑运算符（not > and > or），() 优先级最高。先算算术，再比较，最后逻辑。
💡 逻辑优先级：not 第一级，and 第二级，or 第三级。混合写时先算 not，再 and，最后 or；拿不准就加括号。
💡 闰年规则：能被 400 整除，或者（能被 4 整除 且 不能被 100 整除）才是闰年，用 or 与 and 组合条件。

🔢 奇数偶数判断挑战1 · if–else + 取余

1第一步：输入整数 A
2第二步：用 A % 2 求余数
3第三步：余 0 为偶数
4第四步：否则为奇数
a = int(input("输入整数："))   # 输入整数
if a % 2 == 0:              # 能被 2 整除
    print("偶数")
else:
    print("奇数")          # 否则是奇数

📅 闰年判断挑战2 · and/or 逻辑运算

1第一步：输入年份 y
2第二步：if y%400==0 为闰年
3第三步：elif y%4==0 且 y%100!=0 闰年
4第四步：否则为平年
y = int(input("输入年份："))   # 输入年份
if y % 400 == 0:            # 被 400 整除
    print("闰年")
elif y % 4 == 0 and y % 100 != 0:   # 被4整除且不被100整除
    print("闰年")
else:
    print("平年")          # 其它是平年
