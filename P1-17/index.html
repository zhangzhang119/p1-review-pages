1核心知识点
range()[reɪndʒ]范围
  • Python 的内置函数，不用 import 就能用
  • 返回一个 range 类型的有序数列
  • 最多可填 3 个参数，最少 1 个
  • 生成的数字 取头不取尾
range(5)    # 得到 [0, 1, 2, 3, 4]
range(stop)[stɒp]停止 / 终点
  • 只写 1 个参数：终点 stop
  • 数列从 0 开始，到 stop 前停止
  • 默认步长是 1
  • 例：range(5) → [0, 1, 2, 3, 4]
range(5)    # 0、1、2、3、4
range(start, stop)[stɑːrt]起点
  • 写 2 个参数：起点 start、终点 stop
  • 从 start 开始，到 stop 前停止
  • 参数只能是整数
  • 例：range(1, 10) → [1, 2, …, 9]
range(1, 10)   # 1 到 9
range(start, stop, step)[step]步长
  • 写 3 个参数：起点、终点、步长
  • step 是每次增加的数
  • step 写负数可倒序取数
  • 例：range(1, 10, 3) → [1, 4, 7]
range(1, 10, 3)  # 1、4、7
for i in range()[fɔːr]对于 / 循环
  • for 循环用来重复执行代码
  • 把 range 里的数依次交给 i
  • 冒号后缩进的是循环体
  • 常与 range() 搭配做计数
for i in range(3):
    print(i)    # 0 1 2
💡 取头不取尾：range(1, 10) 包含开头的 1，但不包含结尾的 10。想取到 10，要写成 range(1, 11)。
💡 参数只能是整数：range() 里不能写小数，range(1.5, 10) 会报错。需要小数步长要用别的方法。
💡 循环体要缩进：for 后面是冒号，下一行必须缩进，不然代码不在循环里，只会执行一次。

3程序参考 · 倍数统计与六芒星

🔢 统计 100 以内所有 3 的倍数程序 · for + range + print

1第一步：创建变量 num = 0（用来计数）
2第二步：for 循环 range(3,100,3) 产生 3 的倍数
3第三步：每循环一次 num = num + 1
4第四步：print 打印结果
num = 0
for i in range(3, 100, 3):
    num = num + 1
print("一共有%s个3的倍数" % (num))

🌟 绘制粉色六芒星程序 · for + turtle.forward + left

画笔设为粉色、粗细 2；for 循环让 i 从 100 依次减 1 到 -99，每次前进 i（负数则后退）并左转 120°，最终画出粉色六芒星。

1第一步：导入 turtle，画笔粗细 2、颜色 pink
2第二步：for 循环 range(100, -100, -1)
3第三步：每次 forward(i)、left(120)
4第四步：done() 收工
import turtle
turtle.pensize(2)
turtle.pencolor("pink")
for i in range(100, -100, -1):
    turtle.forward(i)
    turtle.left(120)
turtle.done()
