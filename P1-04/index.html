1核心知识点
dot()[dɑːt]圆点
  • turtle 库的常用函数
  • 在画笔当前位置画一个实心圆点
  • dot(size, color)：第一个参数是直径，第二个是颜色
  • 比如 dot(60, "yellow") 画一个直径 60 的黄色圆
turtle.dot(60, "yellow")   # 画一个黄色圆点
bgcolor()[bækɡraʊnd]背景
  • 用来设置画布背景颜色
  • 括号里写带引号的英文颜色名
  • 比如 bgcolor("red") 把背景变红
  • 一般写在画图形之前
turtle.bgcolor("red")      # 背景变成红色
speed()[spiːd]速度
  • 设置画笔移动速度
  • 参数范围 0 到 10
  • 0 最快，1 到 10 数值越大越快，1 最慢
  • 比如 speed(0) 让画图瞬间完成
turtle.speed(0)            # 最快速度
pencolor()[ˈkʌlər]颜色
  • 设置画笔（线条）颜色
  • 括号里写带引号的英文颜色名
  • 比如 pencolor("yellow") 画笔变黄
  • 要和 bgcolor 区分：一个管线条，一个管背景
turtle.pencolor("yellow") # 画笔变黄色
pensize()[saɪz]大小 / 粗细
  • 设置画笔粗细
  • 括号里写数字，数字越大线越粗
  • 比如 pensize(100) 画出很粗的杆
  • 要写在画线之前才生效
turtle.pensize(100)       # 画笔粗细 100
💡 dot 的两个参数：dot(直径, 颜色)，第一个是圆的大小，第二个是颜色名；颜色名要用英文引号包起来。
💡 背景 vs 画笔颜色：bgcolor() 改的是整张画布的底色，pencolor() 改的是线条和圆点描边颜色，两者不一样，别写混。
💡 引号规则：颜色名是文字，必须加英文引号，例如 bgcolor("red")；而 speed(0)、dot(60, ...) 里的数字是数值，不能加引号。

🛞 绘制轮胎招牌广告招牌 · bgcolor + dot

浅灰背景上，用三个不同大小的圆点叠出轮胎（外胎、轮毂、轮轴）。

1第一步：导入库，背景设为 lightgrey
2第二步：dot(400, "black") 画外胎
3第三步：dot(250, "lightsteelblue") 画轮毂
4第四步：dot(50, "slategrey") 画轮轴，隐藏结束
import turtle as t
t.bgcolor("lightgrey")        # 浅灰背景
t.dot(400, "black")         # 外胎
t.dot(250, "lightsteelblue")  # 轮毂
t.dot(50, "slategrey")       # 轮轴
t.hideturtle()
t.done()

🌙 绘制月亮海报月亮海报 · dot + forward

深蓝背景上画黄色圆月，再向前移动后用同色圆点遮出月牙。

1第一步：背景设为 midnightblue
2第二步：dot(200, "yellow") 画圆月
3第三步：pencolor("yellow")，forward(50) 移动画笔
4第四步：dot(150, "midnightblue") 遮出月牙，隐藏结束
import turtle as t
t.bgcolor("midnightblue")    # 深蓝夜空
t.dot(200, "yellow")         # 圆月
t.pencolor("yellow")
t.forward(50)                 # 向右移动画笔
t.dot(150, "midnightblue")    # 同色圆点遮出月牙
t.hideturtle()
t.done()

🏋️ 绘制哑铃商标健身房商标 · pensize + dot

用粗笔画出握手横杆，再在两端点上黑色圆点当作铁片。

1第一步：pensize(100)、pencolor("lightblue")，forward(100) 画横杆
2第二步：dot(60, "black") 画右侧铁片
3第三步：pensize(20)、pencolor("brown")，backward(100) 回到左侧
4第四步：dot(60, "black") 画左侧铁片，隐藏结束
import turtle as t
t.pensize(100)
t.pencolor("lightblue")
t.forward(100)               # 画中间握手横杆
t.dot(60, "black")           # 右侧铁片
t.pensize(20)
t.pencolor("brown")
t.backward(100)              # 回到左侧
t.dot(60, "black")           # 左侧铁片
t.hideturtle()
t.done()
