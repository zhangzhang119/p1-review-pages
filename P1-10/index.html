加减乘除 · // 整除 · % 取余 · ** 幂运算

01掌握加、减、乘、除四种基本算术运算
02掌握整除 //、取余 %、幂运算 **三种进阶运算
03用 if 条件判断实现收银金额优惠
1核心知识点
+ -[æd]加减
  • + 把两个数相加，- 把两个数相减
  • 整数与浮点数混合运算，结果自动变成 float
  • 可以直接 print(a + b) 看计算结果
  • 例：5 + 0.8 = 5.8，是整数加小数
a = 5; b = 0.8
print(a + b)    # 5.8
*[ˈmʌltɪplaɪ]乘
  • * 表示相乘
  • 整数 × 浮点数 = 浮点数
  • print(9 * 3) 得到 27
  • 乘法也可以理解成"几次相加"
a = 9; b = 3
print(a * b)    # 27
/[dɪˈvaɪd]除
  • / 表示相除
  • 除法结果永远是浮点数
  • 100 / 5 = 20.0（带小数点）
  • 想要整数结果要用整除 //
a = 100; b = 5
print(a / b)    # 20.0
// %[ˈmɒdʒuloʊ]整除取余
  • // 整除：只留"能分几份"，丢掉余数
  • 7 // 2 = 3（7 个苹果每 2 个一份，分 3 份）
  • % 取余：只留"剩下几个"
  • 7 % 2 = 1（分完还剩 1 个不够分）
print(7 // 2)    # 3（整除）
print(7 % 2)     # 1（取余）
**[paʊər]幂运算
  • ** 表示"几次方"
  • 7 ** 2 = 49，相当于 7 × 7
  • 5 ** 3 = 125，相当于 5 × 5 × 5
  • 幂运算常用于面积、体积等计算
print(7 ** 2)    # 49
print(5 ** 3)    # 125
if[ɪf]如果
  • if 判断条件是否成立
  • 条件为 True 才执行缩进里的内容
  • 金额 > 100 时减 10 元优惠
  • 可以多个 if 叠加享受优惠
if money > 100:
    money = money - 10    # 满100减10
💡 整数与浮点数：只要算式里出现小数（浮点数），结果就自动变成 float；除法 / 的结果永远是浮点数。
💡 // 与 % 的区别：// 只取"能分几份"（7//2=3），% 只取"剩几个"（7%2=1）。两者合起来正好还原原数：3×2+1=7。
💡 抹零写法：手册用 money = money // 1 把小数抹掉取整——任何数整除 1 都得整数（去掉了小数部分）。

🛒 计算水果总金额程序 · input + 运算

智能机器人售卖三种水果，询问每种斤数后计算并输出总金额。

1第一步：初始化三种水果的单价
2第二步：用 float() 获取每种斤数
3第三步：斤数 × 单价 算总金额
4第四步：用 print() 输出金额
a = 3.5; b = 5; o = 5.5        # 苹果/香蕉/橘子单价
ac = float(input("苹果"))           # 苹果斤数
bc = float(input("香蕉"))           # 香蕉斤数
oc = float(input("橘子"))           # 橘子斤数
money = ac*a + bc*b + oc*o          # 总金额
print("总金额为", money)
运行结果
苹果3 香蕉2 橘子1 总金额为 22.5

🎉 优惠后金额扩展 · if 优惠

金额大于 100 减 10 元，大于 50 抹零，可同时享受，最后输出优惠后金额。

1第一步：判断金额 > 100，减 10 元
2第二步：判断金额 > 50，整除 1 抹零
3第三步：两项优惠可叠加
4第四步：输出优惠后的金额
if money > 100:
    money = money - 10        # 满100减10
if money > 50:
    money = money // 1        # 满50抹零取整
print("优惠后", money, "元")
运行结果
优惠后 110 元
