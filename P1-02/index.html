海龟绘图知识点复习

turtle 海龟库 · forward 前进 · pensize 粗细 · pencolor 颜色

02掌握海龟画笔的常用方法
03学习程序的顺序结构
1核心知识点
import turtle[ˈtɜːrtl]海龟
  • 用海龟画图的第一步：导入 turtle 库
  • turtle 是 Python 自带的绘图库，不用额外安装
  • 导入后就可以用 turtle.forward() 这样的函数
  • 也可以写 import turtle as t，之后用 t.forward() 更省事
import turtle              # 导入海龟库
turtle.forward(100)        # 前进 100
turtle.done()               # 绘图结束
forward()[ˈfɔːrwərd]前进
  • 让画笔向前移动指定的距离，边走边画线
  • 括号里写距离（数字），比如 50
  • 海龟一开始头朝右边，前进就是往右画一条线
  • 想画更长的线，就把数字写大一点
import turtle
turtle.forward(50)         # 前进 50
turtle.done()
pensize()[saɪz]大小
  • 设置画笔的粗细
  • 括号里写数字，数字越大线越粗
  • 默认粗细是 1，可以一直用到下一次修改
  • 要写在 forward() 前面才有效果
import turtle
turtle.pensize(12)         # 画笔粗细 12
turtle.forward(50)
turtle.done()
pencolor()[ˈkʌlər]颜色
  • 设置画笔的颜色
  • 括号里写带引号的英文颜色名，比如 "red"
  • 常用颜色：red / gold / blue / green / pink / silver
  • 同样要写在 forward() 前面才有效果
import turtle
turtle.pencolor("red")    # 画笔变红色
turtle.forward(50)
turtle.done()
hideturtle()[haɪd]隐藏
  • 把画笔（小海龟箭头）隐藏起来
  • 画完图再用，画面会更干净好看
  • 一般放在画图之后、done() 之前
  • 想重新显示，用 showturtle()
turtle.hideturtle()         # 隐藏画笔
turtle.done()
done()[dʌn]完成
  • 写在程序的最后一行
  • 作用是固定海龟窗体，告诉程序绘图结束
  • 不加的话，窗口可能一闪就关掉，看不到画
  • 它是海龟三件套的最后一件
turtle.done()               # 绘图结束，窗口保持
💡 海龟三件套：import turtle（导入库）→ turtle.forward(距离)（画一笔）→ turtle.done()（收工）。 每一个海龟程序都离不开这三行。
💡 顺序结构：程序从上往下一行一行执行，谁写在前面谁先执行。 所以想换颜色、改粗细，一定要把 pencolor() / pensize() 写在 forward() 前面，否则这一笔还是用旧的设置画出来的。
💡 引号规则：pencolor("red") 里的颜色名是文字，要用英文引号包起来； pensize(20)、forward(50) 里是数字，不能加引号。

3程序参考 · VR 武器铺

🥢 绘制金箍棒挑战1 · pensize + pencolor

1第一步：设置画笔粗细为 20
2第二步：金色，前进 40
3第三步：红色，前进 120
4第四步：金色，前进 40，隐藏画笔
import turtle
turtle.pensize(20)                  # 画笔粗细 20
turtle.pencolor("gold")           # 金色
turtle.forward(40)                 # 金色部分 40
turtle.pencolor("red")            # 红色
turtle.forward(120)                # 红色部分 120
turtle.pencolor("gold")           # 再变回金色
turtle.forward(40)                 # 金色部分 40
turtle.hideturtle()                # 隐藏画笔
turtle.done()                     # 绘图结束

⚔️ 绘制混天剑挑战2 · 多次改 pensize

1第一步：剑柄，粗细 12，前进 50
2第二步：护手，粗细 30，前进 5
3第三步：剑身，粗细 20，前进 200
import turtle
turtle.pensize(12)                  # 剑柄：细一点
turtle.forward(50)                 # 剑柄 50
turtle.pensize(30)                  # 护手：最粗
turtle.forward(5)                  # 护手 5（很短）
turtle.pensize(20)                  # 剑身：中等
turtle.forward(200)                # 剑身 200
turtle.done()

🔗 设计双节棍挑战3 · 自由创作

给小美设计一款独一无二的武器——双节棍：两根棍子 + 中间一条细细的链子。

1第一步：金色粗棍，前进 35
2第二步：银色粗棍，前进 35
3第三步：粗细改 1，画链子 120
4第四步：银色、金色各 35，收工
import turtle
turtle.pencolor("gold")           # 金色
turtle.pensize(20)                  # 粗棍
turtle.forward(35)
turtle.pencolor("silver")         # 银色
turtle.forward(35)
turtle.pensize(1)                   # 链子：最细
turtle.forward(120)                # 中间的链子
turtle.pensize(20)                  # 恢复粗棍
turtle.forward(35)
turtle.pencolor("gold")           # 换回金色
turtle.forward(35)
turtle.hideturtle()                # 隐藏画笔
turtle.done()
