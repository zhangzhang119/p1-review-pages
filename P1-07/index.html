1核心知识点
input()[ˈɪnpʊt]输入
  • 接收用户从键盘输入的内容
  • 括号里写字符串，用作输入提示语
  • 返回用户输入的内容，类型是字符串
  • 常写成 name = input("请输入名字：")
name = input("请输入你的名字：")  # 等待键盘输入
print()[prɪnt]打印
  • 把内容输出到控制台（屏幕）
  • 括号里可放多个内容，用逗号隔开
  • 也可以直接输出一段字符串
  • 和 input() 搭配做人机交互
print("你好", "我是机器人")   # 逗号分隔多项
name = 值[neɪm]变量赋值
  • 把右边的值存到左边的变量里
  • 例：name = "小程" 把名字存进 name
  • 命名规则：只能字母、下划线、数字
  • 不能以数字开头，区分大小写，不用关键字
name = "小程"                  # 变量 name 存字符串
字符串 +[ˈstrɪŋ]字符串拼接
  • 字符串就是一串文字，要用引号包起来
  • 用 + 把几段字符串连接在一起
  • 例："你好，" + name 拼出完整句子
  • input() 得到的本来就是字符串，可直接拼
print("你好，" + name)       # 拼接后输出
💡 变量是什么：变量就像一个贴了名字的盒子，用 name = 值 把数据放进去，之后喊名字就能取出来用。
💡 命名规则：变量名只能用字母、下划线、数字；不能以数字开头；区分大小写；不能用 if、print 这类关键字。
💡 字符串要加引号："你好" 是字符串要加引号；而变量名 name 不能加引号，加了就变成普通文字了。

3程序参考 · 冷笑话制造机

🤖 基础人机交互打招呼 · print + input

1第一步：print 输出问候语
2第二步：input 询问玩家名字，存到 name
3第三步：print 输出“你好，name”
print("你好，我是笑话机器人！")      # 输出问候
name = input("请输入你的名字：")          # 键盘输入，存到 name
print("你好，" + name)                    # 拼接字符串后输出
运行结果
你好，我是笑话机器人！ 请输入你的名字：小明 你好，小明

😄 冷笑话制造机冷笑话 · print + input + 拼接

1第一步：print 开场白
2第二步：连续 input 收集 人名 / 地名 / 事情
3第三步：print 拼接生成冷笑话
print("你好" , "输入一些信息，我给你讲一个笑话吧！")  # 开场白（逗号分隔多项）
name = input("请输入一个人名：")                       # 收集人名
place = input("请输入一个地名：")                      # 收集地名
thing = input("请输入一件事情：")                      # 收集事情
print("在一个风雨交加的夜晚，" + name + "居然在" + place + "一边吃饭一边" + thing)  # 拼接冷笑话
运行结果
你好 输入一些信息，我给你讲一个笑话吧！ 请输入一个人名：小明 请输入一个地名：学校 请输入一件事情：跳舞 在一个风雨交加的夜晚，小明居然在学校一边吃饭一边跳舞
