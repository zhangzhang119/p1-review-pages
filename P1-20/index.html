1核心知识点
import time[taɪm]时间
  • time 库是 Python 处理时间的工具库
  • 用前要先 import 导入
  • 可以获取电脑当前时间
  • 导入后调用 time.strftime()
import time
strftime()[ˈstrɪŋfaɪm]时间格式化
  • time 库里的时间格式化函数
  • 把当前时间整理成指定样式
  • 括号里填字符串格式
  • 常用 %H %M %S 表示时分秒
time.strftime("%H:%M:%S")
%H %M %S[ˈfɔːmæt]格式符
  • %H 表示小时
  • %M 表示分钟
  • %S 表示秒
  • 用 冒号 / 横线 连接成样式
"%H:%M:%S"  # 时:分:秒
turtle.write()[raɪt]写；编写
  • turtle 里的书写函数
  • 把文字显示在画布上
  • 可以显示各国语言文字
  • 内容可为字符串 / 数字等
turtle.write("妙小程")
font=()[fɒnt]字型；字体
  • write() 的参数，改字体字号
  • 常用楷体 / 隶书 / 黑体等
  • 字体名是字符串
  • 字号用整数
turtle.write("妙小程", font=("楷体", 12))
💡 格式符要加 %：%H、%M、%S 都带百分号，写错了就显示不出正确的时间。
💡 字体名用引号：font=("隶书", 28) 里 "隶书" 是字符串要加英文引号，字号 28 是数字不用引号。
💡 电子时钟要无限刷新：用 while True 循环，每次 clear() 清旧时间、update() 刷新、sleep(1) 等 1 秒再循环。

3程序参考 · 电子时钟三步

⏰ 任务1：控制台显示当前时间程序 · import time + strftime + print

1第一步：import time 导入时间库
2第二步：time.strftime("%H:%M:%S") 获取当前时间
3第三步：print() 输出到控制台
import time
now = time.strftime("%H:%M:%S")
print(now)

🖊️ 任务2：画布显示当前时间程序 · import turtle + write + font

1第一步：import time 和 import turtle as t
2第二步：penup() 抬笔，goto() 移到位置，pencolor() 设颜色
3第三步：strftime() 获取时间，write() 显示并设字体
4第四步：done() 保持画布
import time
import turtle as t
t.penup()
t.pencolor("red")
t.goto(-100, 0)
now = time.strftime("%H:%M:%S")
t.write(now, font=("隶书", 28))
t.done()

🔄 任务3：会走动的电子时钟程序 · while True + clear + update + sleep

1第一步：while True 创建无限循环
2第二步：clear() 清空上一秒旧时间
3第三步：write() 写新时间，update() 刷新
4第四步：sleep(1) 等 1 秒再循环
import time
import turtle as t
t.penup()
t.pencolor("red")
t.goto(-100, 0)
t.tracer(0)
while True:
    t.clear()
    now = time.strftime("%H:%M:%S")
    t.write(now, font=("隶书", 28))
    t.update()
    time.sleep(1)
t.done()
