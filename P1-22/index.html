1核心知识点
random[ˈrændəm]随机的
  • 是 Python 的标准库，不用额外安装
  • 用来产生各种类型的随机数
  • 使用前要先 import random
  • 常用它的 randint() 函数产生随机整数
import random              # 导入 random 库
randint()[ˈrændɪnt]随机整数
  • 是 random 库里的函数，产生随机整数
  • 括号里写范围 a, b，包含两端
  • 例：random.randint(1, 10) 得 1~10 任一整数
  • 常用来随机抽取卡牌编号
import random
y = random.randint(1, 3)      # 产生 1~3 的随机整数
getcard()[ɡet kɑːd]获取卡牌
  • 是 mxcgame 库的函数，从指定角色牌堆抽牌
  • 前两个参数：编号、指定角色
  • 会返回抽到的卡牌，可存进变量
  • 语法：m.getcard(编号, 指定角色)
card = m.getcard(y, cmp)      # 从 cmp 牌堆抽编号 y 的牌
getcard(补牌)[ɡet kɑːd]补牌模式
  • 第三个参数设 True 开启补牌模式
  • 开启后抽到的牌会自动加入该角色补牌堆
  • 默认是 关闭 的
  • 语法：m.getcard(编号, 角色, True)
m.getcard(x, player, True)    # 抽牌并加入 player 补牌堆
💡 随机数范围：random.randint(1, 10) 会产生 1 到 10 之间（包含 1 和 10）的任意一个整数，每次运行结果可能不同。
💡 补牌模式：m.getcard(编号, 角色, True) 的第三个参数 True 表示开启补牌，抽到的牌会自动进入该角色的补牌堆；不加则只是临时抽一张。
💡 无限循环与结束：while True 会一直运行，必须配合 break 才能结束游戏，否则对战会停不下来。

3程序参考 · 卡牌对决·敌方对战

👾 敌方出牌逻辑randint · getcard · attack

获取敌方 1~3 号中的随机卡牌，对玩家发起攻击。

1第一步：用 randint 获取敌方随机编号
2第二步：用 getcard 抽出这张卡牌
3第三步：用 attack 攻击玩家
while True:
    y = random.randint(1, 3)     # 敌方编号 1~3 随机
    cmpcard = m.getcard(y, cmp)  # 抽出敌方卡牌
    m.attack(cmpcard, player)   # 攻击玩家

🔄 补牌机制for · randint · getcard

重复三次，获取玩家 1~6 号的随机卡牌并加入补牌堆。

1第一步：用 for 循环执行三次
2第二步：用 randint 获取玩家随机编号
3第三步：getcard 设为补牌模式
while True:
    for i in range(3):        # 重复三次
        x = random.randint(1, 6) # 玩家编号 1~6 随机
        m.getcard(x, player, True) # 抽牌并加入补牌堆

🏁 游戏结束逻辑print · break

任意一方血量小于等于 0 时，提示胜负并结束对战。

1第一步：玩家血量 ≤0 提示失败
2第二步：用 break 停止对战
3第三步：敌方血量 ≤0 提示成功
while True:
    if hp1 <= 0:                 # 玩家血量耗尽
        m.print("lose")          # 提示失败
        break                       # 停止对战
    elif hp2 <= 0:               # 敌方血量耗尽
        m.print("win")           # 提示成功
        break
