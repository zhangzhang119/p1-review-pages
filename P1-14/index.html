1核心知识点
if 条件:[ɪf]如果 / 条件
  • 多分支的第一个判断，写在最前面
  • 条件成立就执行它下面的语句，然后结束
  • 格式仍是 if 条件:，冒号后换行缩进
  • 后面可以接一个或多个 elif
if bmi <= 16:
    print("过瘦")      # 第一个分支
elif 条件:[ˈɛlɪf]否则如果
  • elif 是“否则如果”，当上面都不成立才检查它
  • 可以有多个 elif，从上往下依次判断
  • 一旦某个 elif 成立，就执行它并结束
  • 它必须写在 if 之后、else 之前
elif bmi <= 18.5:
    print("偏瘦")      # 第二个分支
else:[els]其他 / 兜底
  • 多分支的最后兜底，放在最末尾
  • 前面所有条件都不成立时，才执行 else
  • else 不用写条件，直接写冒号
  • 一个多分支最多有一个 else
else:
    print("过胖")      # 其它情况兜底
float()[floʊt]浮点数 / 小数
  • 把输入转成小数，可带小数点
  • 身高、体重是小数，要用 float()
  • 写成 float(input("身高(m):"))
  • 和 int() 不同，float 能保留小数位
h = float(input("身高(m):"))   # 转成小数
input()[ˈɪnpʊt]输入
  • 从键盘读取用户的一行输入
  • 可写提示文字，如 input("体重(kg):")
  • 得到的是字符串，算数前要转换
  • 配合 float() 才能做乘除计算
w = float(input("体重(kg):"))   # 读取并转小数
**[ˈpaʊər]幂 / 乘方
  • ** 表示“几次方”，如 h**2 是 h 的平方
  • BMI 公式用 w / h**2 计算指数
  • 优先级比乘除还高，先算乘方
  • 注意是两个星号，不是单个
bmi = w / h ** 2        # h 的平方
💡 多分支结构：if 先判断，elif 依次判断，else 兜底；从上到下只执行第一个满足的分支，后面的不再看。
💡 顺序很重要：多分支要把范围从小到大排，先写 bmi <= 16 再写 bmi <= 18.5。 如果反过来，小的范围会被大的先挡住，永远轮不到。
💡 类型转换：input() 得到的是文字，算身高体重要用 float() 转成小数，否则无法做 w / h**2 这样的乘除。

3程序参考 · BMI计算器

⚖️ BMI 值计算器任务一 · input + float

1第一步：输入身高（米）
2第二步：输入体重（kg）
3第三步：用 w / h**2 算 BMI
4第四步：打印 BMI 值
h = float(input("身高(m):"))      # 身高转小数
w = float(input("体重(kg):"))    # 体重转小数
bmi = w / h ** 2              # BMI = 体重 ÷ 身高²
print("BMI值：", bmi)       # 打印结果
运行结果
身高(m):1.75 体重(kg):70 BMI值： 22.857142857142858

🩺 BMI 健康判定任务二 · if–elif–else

1第一步：接任务一，判断 bmi
2第二步：<=16 过瘦，<=18.5 偏瘦
3第三步：<=25 健康，<=30 偏胖
4第四步：其它情况判过胖
if bmi <= 16:
    print("判定：过瘦")
elif bmi <= 18.5:
    print("判定：偏瘦")
elif bmi <= 25:
    print("判定：健康")
elif bmi <= 30:
    print("判定：偏胖")
else:
    print("判定：过胖")      # 兜底分支
运行结果
BMI值：22.8 判定：健康

💧 饮水量计算系统拓展 · 多分支 + 字符串

1第一步：输入杯子容量、体重、工作类型
2第二步：体力 → 体重 × 43.4
3第三步：脑力 → 体重 × 32.6
4第四步：其它 → 体重 × 30，算杯数
# 饮水量计算系统
a = float(input("请输入杯子容量:(ml):"))
b = float(input("请输入体重:(kg):"))
work = input("请输入工作类型（体力/脑力/其他):")
if work == "体力":
    water = b * 43.4
elif work == "脑力":
    water = b * 32.6
else:
    water = b * 30
print("你每天的饮水量是", water // a, "杯")
运行结果
请输入杯子容量:(ml):300 请输入体重:(kg):60 请输入工作类型（体力/脑力/其他):体力 你每天的饮水量是 8 杯
