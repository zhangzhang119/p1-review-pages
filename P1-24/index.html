shoot 射击 · hit 击中 · skill 技能 · move 移动

01用 shoot() 让玩家射击并击中
02让 boss 随机移动释放技能（move / skill）
03判断胜负结束游戏（break）
1核心知识点
shoot()[ʃuːt]射击
  • 是 mxcgame 库里的函数，让角色发出射击
  • 括号里写发出射击的角色
  • 语法：m.shoot(发出射击角色)
  • 例：m.shoot(player) 玩家射击
m.shoot(player)              # 玩家发出射击
hit()[hɪt]击中
  • 是 mxcgame 库里的函数，判断攻击是否命中
  • 命中返回 True，否则返回 False
  • 常配合 if 扣减血量
  • 语法：m.hit(攻击角色, 被攻击角色)
if m.hit(player, boss):       # 玩家击中 boss
    hp2 = hp2 - 1               # boss 血量减 1
skill()[skɪl]技能
  • 是 mxcgame 库里的函数，让角色随机释放技能
  • 括号里写释放技能的角色
  • 语法：m.skill(角色)
  • 例：m.skill(boss) boss 放技能
m.skill(boss)                 # boss 释放技能
move()[muːv]移动
  • 是 mxcgame 库里的函数，让角色随机移动
  • 括号里写移动的角色
  • 语法：m.move(角色)
  • 例：m.move(boss) boss 随机走位
m.move(boss)                  # boss 随机移动
💡 射击与命中：m.shoot(角色) 让指定角色发出射击，m.hit(攻击, 被攻击) 判断是否命中并返回 True，命中后再扣减血量。
💡 按键判断要加引号：m.key()=="left"、=="right"、=="space" 中的文字是字符串，一定要加英文引号；变量（如 player、boss）不能加引号。
💡 结束游戏：用 if hp<=0 判断胜负，再用 break 跳出循环；胜利打印 "win"，失败打印 "lose"。

3程序参考 · 火力全开

🎮 玩家角色功能设置key · shoot · hit

玩家用左右键移动，按空格射击；击中 boss 则 boss 血量减 1。

1第一步：左右键改变玩家 x 坐标
2第二步：空格键 shoot 射击
3第三步：hit 命中则 boss 血量减 1
import mxcgame as m
hp2 = 80
while True:
    if m.key() == "left":        # 按下左键
        player.x = player.x - 10  # 左移
    if m.key() == "right":       # 按下右键
        player.x = player.x + 10  # 右移
    if m.key() == "space":       # 按下空格
        m.shoot(player)            # 玩家射击
    if m.hit(player, boss):       # 命中 boss
        hp2 = hp2 - 1               # boss 血量减 1
运行结果
（玩家移动并射击，命中 boss 时 boss 血量从 80 减少）

👹 boss 角色功能设置move · skill · hit

boss 随机移动、随机释放技能；技能命中玩家则玩家血量减 1。

1第一步：move 让 boss 随机移动
2第二步：skill 让 boss 随机放技能
3第三步：hit 命中玩家则血量减 1
import mxcgame as m
hp1 = 20
while True:
    m.move(boss)                 # boss 随机移动
    m.skill(boss)                # boss 释放技能
    if m.hit(boss, player):       # 技能命中玩家
        hp1 = hp1 - 1               # 玩家血量减 1
运行结果
（boss 不断移动并放技能，命中玩家时玩家血量从 20 减少）

🏁 游戏结束设置print · break

boss 血量归零提示胜利，玩家血量归零提示失败，均结束游戏。

1第一步：boss 血量 ≤0 提示 win
2第二步：用 break 停止游戏
3第三步：玩家血量 ≤0 提示 lose
import mxcgame as m
hp1 = 20
hp2 = 80
while True:
    if hp2 <= 0:                 # boss 血量耗尽
        m.print("win")           # 提示胜利
        break
    if hp1 <= 0:                 # 玩家血量耗尽
        m.print("lose")          # 提示失败
        break
运行结果
win （或） lose
