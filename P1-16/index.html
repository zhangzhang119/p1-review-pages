1核心知识点
for[fɔː(r)]为了 / 循环
  • for 是 Python 里的循环关键字
  • 用来把一件事重复做很多遍
  • 常和 in、range() 搭配使用
  • 格式：for i in range():，冒号后缩进
for i in range(4):
    turtle.forward(100)   # 重复 4 次
range()[reɪndʒ]范围
  • range() 产生一组有序数列
  • 默认从 0 开始，每次加 1
  • range(5) 得到 0,1,2,3,4 共 5 个数
  • 参数不能为 0，否则不产生任何数
for i in range(4):      # i 依次取 0,1,2,3
    turtle.forward(100)
in[ɪn]在…里
  • in 表示“从…里面逐个取”
  • for i in range(): 把数列里的数依次赋给 i
  • 每一次循环，i 换成下一个数
  • 是 for 循环的固定写法之一
for i in range(100):    # i 从 0 取到 99
    turtle.forward(i)
turtle.left()[left]左转
  • 让海龟向左转指定角度
  • 画正方形每次转 90 度
  • 括号里写角度数字
  • 配合 forward 才能画出拐角
import turtle
turtle.left(90)            # 向左转 90 度
turtle.forward()[ˈfɔːrwərd]前进
  • 让海龟向前移动并画线
  • 括号里写前进距离
  • 放进 for 循环就能重复画边
  • 和 left 交替，画出闭合图形
for i in range(4):
    turtle.forward(100)   # 画一条边
    turtle.left(90)
turtle.done()[dʌn]完成
  • 写在海龟程序的最后一行
  • 作用是固定窗口，告诉程序绘图结束
  • 不加窗口可能一闪就关
  • 是海龟绘图的标准收尾
turtle.done()               # 绘图结束，窗口保持
💡 循环结构：把“重复做相同或类似的事”写成一次循环，让电脑自动重复，省去复制粘贴 4 段甚至 100 段程序。
💡 range() 用法：range(4) 产生 0,1,2,3 共 4 个数，循环体就执行 4 次；想循环几次就写几，参数不能为 0。
💡 for 固定写法：for i in range(次数): 冒号不能丢，循环体必须缩进。想让边长变化，就把变量 i 写进 forward(i)。

🟦 for循环画正方形挑战1 · for + range 简化

1第一步：导入 turtle 库
2第二步：for i in range(4) 循环 4 次
3第三步：循环里 forward(100) 画边
4第四步：left(90) 转角，done() 收工
import turtle
for i in range(4):           # 重复 4 次
    turtle.forward(100)     # 画一条边
    turtle.left(90)          # 向左转 90 度
turtle.done()                 # 绘图结束

🌀 边长递增的正方形挑战2 · 变量 i 进循环体

1第一步：导入 turtle 库
2第二步：for i in range(100)
3第三步：forward(i) 边长随 i 增大
4第四步：left(90) 旋转，done() 收工
import turtle
for i in range(100):         # i 从 0 到 99
    turtle.forward(i)         # 边长等于 i，越来越大
    turtle.left(90)            # 每次转 90 度
turtle.done()                 # 绘图结束
